# 🕷️ Automated Web Scraper & Data Extractor Engine

A resilient Node.js web scraping solution built with Puppeteer Stealth to bypass basic bot protection, extract structured dynamic web data, and output directly to clean CSV files.

---

## ✨ Features
- **Stealth Browsing:** Bypasses basic anti-bot scripts using `puppeteer-extra-plugin-stealth`.
- **Dynamic DOM Parsing:** Handles JavaScript-rendered single-page apps (SPAs).
- **CSV & Database Exporters:** Outputs structured datasets ready for business analysis.
- **Custom Footprints:** Spoofs user-agents and viewports.

---

## 🛠️ Tech Stack
- **Engine:** Node.js, Puppeteer Extra, Stealth Plugin
- **Export Formats:** CSV (`csv-writer`), SQLite3
